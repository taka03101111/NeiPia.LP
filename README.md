## ファイル構成

- `index.html` — 5セクション、料金・申込み前の確認事項、フッター
- `styles.css` — レイアウト、配色、レスポンシブ表示（色は先頭のCSS変数で調整）
- `app.js` — 講座カード生成、リンク検証、会員／非会員タブ操作
- `data/courses.js` — 講座データとサンプル講座
- `assets/courses/` — 本番用講座画像（横13:縦9）

## ローカルで見る

`index.html` をブラウザで開くか、このフォルダをカレントディレクトリにして簡易HTTPサーバーを起動します。

```powershell
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。サーバー停止は `Ctrl+C` です。

## 講座の追加・編集

`data/courses.js` の `window.NEIPIA_COURSES` 配列を編集します。カードは配列から自動生成されます。

- `id`: 計測や運用に使う固定識別子。個人情報を入れない
- `title`, `description`: 確認済みの講座名と紹介文
- `sessions`: 1〜4の整数
- `minutesPerSession`: 1回あたりの分数（未確認なら設定しない）
- `audience`: 確定した場合のみ設定
- `usesAimAt`: `true` / `false` / `null`（未確認なら `null`）
- `bookingUrl`: 講座別の予約先。HTTPS URLのみ有効。空欄や無効なURLなら問い合わせ先に切り替わる
- `available`: 受付停止中なら `false`。ボタンは開講予定の問い合わせになる
- `isSample`: プレビュー用の架空講座なら `true`。実講座へ差し替えるときは `false`
- `publishReady`: 公式情報・画像・料金条件・導線を運営が確認した講座だけ `true` にする

## 13:9画像を差し替える

画像を `assets/courses/` に置き、例のように相対パスと代替テキストを設定します。

```js
thumbnail: "assets/courses/inquiry-workshop.webp",
thumbnailAlt: "講座内容を表す正式なサムネイル画像",
```

画像パスは `assets/courses/` 配下のみ受け付けます。未設定時は「画像準備中」のデザインプレースホルダーが表示されます。カードの枠はCSSで13:9に固定されます。

## 予約先を設定する

各講座の `bookingUrl` に確認済みHTTPS URLを入力します。未設定・URL形式不正の場合は「講座について問い合わせる」ボタンになり、公式LINE（`https://lin.ee/6kQiLaY`）へ進みます。予約先が異なる場合は講座ごとに変更してください。ページは予約成立や決済を処理しません。`data-course-id` を付けているため、後から計測イベントを追加できます。

## 公開プレビューから本番データへ切り替える

1. `data/courses.js` のサンプルを、運営が確認した講座データへ置き換える。
2. 実講座ごとに `isSample: false`、`publishReady: true` にする。`publishReady: true` でない講座とサンプル講座は本番表示から自動で除外されます。
3. `app.js` 冒頭の `SITE_CONFIG.previewMode` を `false` に変更する。サンプル表示とサンプルカードを止めます。
4. 実画像、予約リンクまたは問い合わせ先、受付状況、料金・利用条件を実機で再確認する。
5. 公式サイトへの組み込み方式と公開先URLを運営・サイト管理者と決定する。このフォルダには公開処理や既存サイトの変更は含まれません。
